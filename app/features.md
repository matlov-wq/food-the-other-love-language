# Features

## MVP (build first)

| Feature | Notes |
|---|---|
| Recipe list / browse by category | Categories from `docs/vision.md` |
| Recipe detail view | Must render grouped ingredients + inline repeated measurements + doneness cues — see `docs/recipe-standards.md` |
| Serving scaler | Recompute ingredient amounts proportionally |
| Favorites | Local storage is fine for MVP, no auth needed yet |
| "If You Feel Like It" section | Visually distinct from required steps |
